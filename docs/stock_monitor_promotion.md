# 把盯盘焦虑，变成一条清晰的交易计划

## ESP32 股票行情辅助终端

这不是一台“预测明天涨跌”的机器，也不是自动下单工具。

它更像桌面上的一小块交易纪律屏：帮你持续关注最多 8 只股票，把价格、趋势、入场区间、失效价、目标价和风险收益比放在眼前，再用 OLED、RGB 灯和震动及时提醒。

对刚接触股票的人来说，它最重要的价值不是告诉你“买什么”，而是帮助你在准备交易时，先看清三件事：

1. 现在是不是合适的位置？
2. 如果判断错了，从哪里退出？
3. 这笔交易的潜在收益，值不值得承担这份风险？

## 可直接转发的简短介绍

> 这是一台基于 ESP32 的桌面股票行情辅助终端。它能同时关注 8 只股票，用 128x64 OLED 显示现价、日内走势、RSI、MACD、VWAP、布林带和综合评分，并给出 `READY / WAIT / AVOID` 状态、入场区间、失效价、目标价和盈亏比。价格到上限或下限时，会通过 RGB 灯、持续震动和可选声音提醒。它不是荐股神器，也不会自动下单，更像一块帮助新手执行交易纪律的小屏幕。

> 本设备提供行情展示、技术指标计算和交易决策辅助，不构成投资建议，不保证收益，也不会代替你自己的判断。

## 它解决什么问题

### 1. 信息很多，但真正需要看的内容很少

手机上同时开着行情、资讯、股吧和交易软件，信息越来越多，反而很难专注于价格位置和风险计划。

这块终端只保留与交易执行最相关的信息：现价、涨跌幅、日内走势、关键指标、趋势评分、入场区间、止损价和目标价。

### 2. 盘中容易追高，也容易凭感觉卖出

价格上涨时，人容易担心错过；价格下跌时，又容易临时改变计划。

设备会把交易条件提前固定下来：

- `ENTRY` 告诉你合理的关注区间。
- `STOP` 告诉你判断失效的位置。
- `TGT` 告诉你计划中的目标位置。
- `R` 告诉你潜在收益和风险的比例。

它不能消除情绪，但可以减少“看到涨了就追”和“跌了不知道怎么办”的临场混乱。

### 3. 不可能一直盯着屏幕

设备支持每只股票独立设置上限和下限提醒。

到达价格区间后，会通过 RGB 灯、震动和声音反馈，不需要频繁解锁手机。

震动已经采用接近手机的持续或多脉冲节奏，价格提醒约持续 1.65 秒，不再是短促的一次点击。

### 4. 想关注几只股票，但不想来回切换

最多可以配置 8 只股票。

K1 和 K2 用于切换股票，K3 立即刷新，K4 在四个分析页面之间切换，实体按键和 Web 页面按钮使用同一套操作逻辑。

### 5. 启动后就能看到当天的行情上下文

设备启动后会主动拉取当天可取得的日内行情，并加载分钟数据进行分析。

不需要从早上开盘开始一直运行，也不要求历史数据必须先由设备在运行过程中慢慢积累。

行情数据来自第三方接口，刷新周期最短 15 秒，默认 30 秒。

## 适合谁

- 刚开始学习股票，希望建立基本交易纪律的人。
- 有工作，不能长时间盯盘，但需要价格提醒的人。
- 想同时关注几只股票，又不愿频繁打开手机的人。
- 喜欢桌面硬件、ESP32、OLED 和电子制作的人。
- 已经有自己的判断，但需要一个固定位置查看关键数字的人。

## 不适合谁

- 想寻找“稳赚信号”或“明天必涨股票”的人。
- 希望设备自动下单、自动托管账户的人。
- 需要交易所级毫秒行情和高频交易能力的人。
- 不愿意学习止损、仓位和风险控制的投资者。

## 它通过什么方式工作

可以把设备理解成一条很短的决策链：

```text
腾讯行情与当天分钟数据
          |
          v
计算 EMA、MACD、RSI、VWAP、BOLL、量比等指标
          |
          v
判断趋势、入场区间、失效价、目标价和盈亏比
          |
          v
OLED 显示 + RGB 灯语 + 震动/声音提醒
```

所有核心分析都在设备本地完成。

手机主要用于配置 Wi-Fi、股票列表、刷新周期、价格上下限和反馈方式，也可以远程操作 K1-K4。

## 一眼看懂四页 OLED

设备使用 1.3 英寸、128x64 分辨率的 SH1106 或 SSD1306 OLED。

屏幕不会显示 `STOCK MONITOR`、`WIFI ONLINE` 这类占据空间的说明文字，而是把像素优先留给数字、走势和交易信息。

顶部只保留股票代码、当前时间和星期。底部用 4 个小型页面标记表示当前位置。

### 第一页：报价页

先看最重要的市场状态。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 股票代码、当前时间、星期 |
| 主视觉 | 尽可能大的当前价格 |
| 中部 | 当天日内走势线 |
| 价格变化 | 涨跌幅、涨跌额 |
| 日内范围 | 最高价、最低价 |
| 成交情况 | 成交量、成交额 |

这一页适合快速确认：现在大概是什么价格，今天走势偏强还是偏弱。

### 第二页：指标页

这一页回答“当前结构有没有配合”。

| 指标 | 作用 |
| --- | --- |
| `RSI` | 判断是否过热、过冷或处在相对健康区间 |
| `MACD` | 观察短期动能方向和柱体变化 |
| `EMA` | 比较快慢均线，判断趋势是否向上 |
| `量比` | 观察当前成交量相对近期水平是否放大 |

这一页使用更大的关键数字，避免把指标挤成一排难以辨认的小字。

### 第三页：分析页

这一页把多个信号整理成更容易理解的市场结构。

| 区域 | 内容 |
| --- | --- |
| 综合评分 | `SCORE` 与趋势方向 |
| 价格参照 | 开盘价、昨收价 |
| 当日均价 | `VWAP` 与当前价格偏离 |
| 波动范围 | 布林带下轨、上轨 |

`SCORE` 是便于快速观察的启发式评分，不是经过收益保证验证的“准确率”。

### 第四页：决策页

这是最适合新手反复查看的一页。

| 字段 | 含义 |
| --- | --- |
| `READY` | 当前条件与交易规则同时满足 |
| `WAIT` | 条件还没完全形成，或价格不在合适区间 |
| `AVOID` | 当前结构不利，不提供入场价位 |
| `NO DATA` | 当天数据或指标尚不足 |
| `ENTRY` | 当前计算出的入场关注区间 |
| `STOP` | 判断失效、应执行风险控制的参考价 |
| `TGT` | 当前结构对应的目标参考价 |
| `R` | 潜在收益与风险的比值 |

这里的英文尽量保持短而统一，是为了在 128x64 屏幕上给数字留出足够空间。

## `READY`、`WAIT`、`AVOID` 应该怎么理解

### `READY` 的条件满足

设备只有在以下条件同时满足时才显示 `READY`：

- EMA 快线高于慢线。
- MACD 柱体为正。
- 当前价格高于 VWAP。
- RSI 位于 45 到 68 之间。
- 当前价格位于 VWAP 入场区间。
- 当前价格没有明显过度延伸。
- 目标价与止损价形成的盈亏比至少为 2.0。

`READY` 表示“规则条件已经对齐”，不表示股票一定上涨，也不表示任何价格都可以买入。

实际使用时，还应确认企业基本面、市场环境、仓位和自身风险承受能力。

### `WAIT` 是等待，不是催促

`WAIT` 往往意味着趋势还没有完全确认，或者价格离合理入场区太远。

这时设备仍会保留计算出的关键价位，方便你等价格回到区间，而不是因为看到上涨就追进去。

### `AVOID` 是明确的暂停

当 EMA、MACD 和 VWAP 没有形成多头一致，或结构明显偏弱时，设备会显示 `AVOID`，并隐藏入场区间。

对新手来说，`AVOID` 最重要的意义是：今天没有合适机会，也可以是一种正确的操作。

## 入场、止损和目标价怎么形成

### 入场区间

入场区间围绕当日 `VWAP` 生成，大约是从 VWAP 下方 0.3% 到上方 0.6%。

它表达的是“相对合理的关注区域”，不是精确到分的买入指令。

### 失效价

`STOP` 根据布林带宽度、当前价格和布林下轨综合计算，风险距离通常限制在约 1% 到 3% 之间。

价格到达失效位置，说明原先的短线条件已经不再成立。

### 目标价

`TGT` 取布林上轨、当天高点和当前价格中的较高位置，用来观察当前结构下可能的目标空间。

### 盈亏比

`R` 等于潜在目标空间除以失效距离。

设备只有在 `R` 至少达到 2.0 时才允许进入 `READY`，意思是潜在空间至少约为计划风险的 2 倍。

盈亏比高并不代表成功率一定高，它只是帮助你把“赚多少”和“可能亏多少”放在一起比较。

## 新手可以按这个顺序使用

### 第一步：选股

用 K1 和 K2 切换已经配置好的股票，或直接在手机 Web 页面点击虚拟 K1-K4。

### 第二步：看报价页

先确认现价、涨跌幅、日内高低点和走势，不要一上来只看 `READY`。

### 第三步：看指标和分析页

确认趋势、动能、RSI、VWAP 和布林带是否互相配合。

### 第四步：看决策页

- 显示 `READY` 时，再确认当前价格是否位于 `ENTRY` 区间。
- 显示 `WAIT` 时，不追高，等待价格或结构回到计划范围。
- 显示 `AVOID` 时，不参与，等待结构修复。
- 显示 `NO DATA` 时，不强行解读，等数据准备完成。

### 第五步：买入前先看风险

在真正下单前，先看清楚：

1. `STOP` 在哪里。
2. `R` 是否足够覆盖风险。
3. 自己能接受的最大亏损是多少。
4. 仓位是否会让一次止损影响正常生活。

### 第六步：按计划处理卖出

- 价格接近或到达 `TGT` 时，按预先计划考虑止盈或保护利润。
- 价格到达 `STOP` 时，承认原判断失效，不用“再等等”替代纪律。
- 价格一直在 `ENTRY` 之外时，不因为怕错过而追单。
- 市场结构转弱时，重新查看 `READY/WAIT/AVOID`，不要只盯着成本价。

这套方式不能保证每笔交易正确，但能让买入和卖出都有依据。

## RGB 灯语：不点亮屏幕，也知道设备在表达什么

RGB 灯分为两种：

- 持续显示的“基础状态”，告诉你系统、网络和数据目前是否正常。
- 短暂覆盖的“事件灯语”，告诉你刚刚发生了什么。

中国股市习惯红涨绿跌，因此上涨提醒使用红色，下跌提醒使用绿色。

### 基础状态灯语

| 状态 | 灯语 |
| --- | --- |
| 启动 | 蓝色慢呼吸 |
| Wi-Fi 断开 | 琥珀色呼吸 |
| Wi-Fi 连接中 | 亮蓝色快呼吸 |
| 系统降级 | 琥珀色慢呼吸 |
| 尚未配置股票 | 紫色呼吸 |
| 等待首条行情 | 青色呼吸 |
| 正在刷新 | 亮青色快呼吸 |
| 行情新鲜 | 暗绿色常亮 |
| 行情过期 | 琥珀色呼吸 |
| 行情错误 | 红色呼吸 |
| 本地 AP 模式 | 蓝色慢呼吸 |
| 就绪但没有股票信号 | 暗蓝色常亮 |

### 瞬时事件灯语

| 事件 | 灯语 |
| --- | --- |
| 上涨价格提醒 | 红色快闪，约 2.4 秒 |
| 下跌价格提醒 | 绿色快闪，约 2.4 秒 |
| 刷新失败 | 红色三闪 |
| 配置保存失败 | 红橙色三闪 |
| Wi-Fi 断开 | 橙色双闪 |
| 系统降级 | 琥珀色三闪 |
| 刷新成功 | 绿色双闪 |
| 开始刷新 | 青色双闪 |
| Wi-Fi 连接成功 | 青绿色双闪 |
| 配置保存成功 | 冰蓝色双闪 |
| 手机连接设备 | 冷白脉冲 |
| 按键导航 | 白色短脉冲 |

价格提醒和故障事件的优先级更高，普通导航不会打断重要提醒。

## 震动语义：更像手机的反馈

设备不再只用一次很短的震动表示所有状态，而是给不同业务安排不同节奏。

| 场景 | 震动节奏 | 总时长 |
| --- | --- | ---: |
| 按键导航 | 1 次 180 ms | 180 ms |
| 开始刷新 | 2 次 180 ms，间隔 90 ms | 450 ms |
| 刷新成功 | 1 次 350 ms | 350 ms |
| 刷新失败 | 2 次 500 ms，间隔 200 ms | 1200 ms |
| 价格提醒 | 2 次 700 ms，间隔 250 ms | 1650 ms |
| 配置保存成功 | 1 次 320 ms | 320 ms |
| 配置保存失败 | 2 次 450 ms，间隔 180 ms | 1080 ms |
| Wi-Fi 连接中 | 2 次 220 ms，间隔 110 ms | 550 ms |
| Wi-Fi 连接成功 | 2 次 350 ms，间隔 130 ms | 830 ms |
| Wi-Fi 断开 | 2 次 550 ms，间隔 220 ms | 1320 ms |
| 系统降级 | 3 次 420 ms | 1620 ms |

可以在 Web 页面选择：

- 震动 + 声音
- 仅震动
- 仅声音
- 静音

在家或办公室可以关闭声音，只用震动和灯语；夜间也可以切换为静音。

## K1-K4 怎么操作

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| K1 | 上一只股票 | 跳到第一只 |
| K2 | 下一只股票 | 跳到最后一只 |
| K3 | 立即刷新 | - |
| K4 | 切换报价、指标、分析、决策页 | 回到报价页 |

Web 页面上的 K1-K4 也可以点击和长按。

它们不是另一套模拟控制，而是直接把操作注入与实体按键相同的业务流程，因此页面和设备的切换、刷新行为保持一致。

## 手机怎么配置

设备会提供本地 Wi-Fi 配置入口：

| 项目 | 内容 |
| --- | --- |
| Wi-Fi 名称 | `StockMonitor` |
| 密码 | `wemosr32` |
| 配置地址 | `http://192.168.4.1/` |

在配置页面可以完成：

- 扫描并连接家里的 2.4 GHz Wi-Fi。
- 添加和删除股票，最多 8 只。
- 设置 15 到 3600 秒的刷新周期。
- 为每只股票分别设置上限和下限价格提醒。
- 选择震动、声音或静音模式。
- 使用 Web 版 K1-K4 操作设备。

Web 页面还会显示每只股票的现价、当天最高、当天最低和涨跌幅。

## 一次完整的使用场景

早上到工位后，给设备通电。

设备连接 Wi-Fi，拉取当天可取得的行情和分钟数据，然后开始按设定周期刷新。

你从第一只股票开始，用 K4 查看报价、指标、分析和决策页。

如果显示 `AVOID`，说明当前结构不适合按这套规则参与，继续观察或切换股票。

如果显示 `WAIT`，记住屏幕上的 `ENTRY`，等待价格回到区间，不因为短线拉升追进去。

如果显示 `READY`，再次确认价格确实位于 `ENTRY` 附近，并先看 `STOP` 和 `R`。

决定交易后，按 `STOP` 定义风险，按 `TGT` 规划目标。价格触达预设上下限时，RGB 灯和马达会提醒你回到屏幕前。

收盘后关闭设备即可。第二天启动时，设备会重新获取当天可取到的行情，不需要从前一晚一直待机到来日开盘。

## 硬件组成

| 部件 | 作用 |
| --- | --- |
| ESP32-WROOM-32 | 网络连接、数据分析、业务控制 |
| 1.3 英寸 OLED | 显示行情和交易决策 |
| RGB 指示灯 | 显示系统、网络和价格事件 |
| 震动马达 | 提供接近手机的触觉提醒 |
| 蜂鸣器 | 提供可关闭的声音提醒 |
| K1-K4 | 本地操作 |
| USB 供电 | 日常运行 |

如果自己组装，裸震动马达不能直接接到 ESP32 GPIO。

马达需要三极管或 MOSFET 驱动、基极或栅极电阻以及续流二极管。购买带驱动模块的震动马达更省事。

## 设备边界

### 它不是实时交易系统

行情由第三方接口提供，默认每 30 秒刷新，最短 15 秒，不等同于交易所逐笔实时行情。

网络异常、接口波动、休市和第三方数据延迟都可能影响显示。

### 它不会自动下单

设备只负责展示、分析和提醒。是否交易、交易多少、是否止损，始终由使用者决定。

### 它不预测必然涨跌

EMA、MACD、RSI、VWAP、布林带和量比都是基于历史价格与成交数据的统计工具。

任何指标都可能失效。`READY` 只是规则条件满足，不是收益承诺。

### 它不能替代仓位和风险管理

单次止损、总资金回撤、分散程度和交易频率，都比某一个信号更重要。

如果连续亏损或情绪受到影响，应停止交易，而不是不断寻找更强的“信号”。

## 一句话介绍

这是一台放在桌面上的股票行情与交易纪律终端：它把当天行情、关键技术指标、入场区间、止损价、目标价和风险收益比压缩到一块小屏幕上，再用 RGB 灯和震动提醒你，帮助新手少一点追涨杀跌，多一点计划执行。
